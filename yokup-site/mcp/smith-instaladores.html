Guía para dar de alta perfiles ficticios de España y Portugal y verificar cada uno mediante el MCP de Yokup. El lote está preparado; publicar esta guía no crea las cuentas.

El alta inicial usa la API REST.

El MCP actual no tiene una herramienta para crear instaladores. Primero se crea la cuenta en la API; después se emite un token propio y se verifica por MCP. El token del MCP general de Yokup no permite operar cuentas de instaladores.

El recorrido de Smith

  1. Preparar el lote. Descargar el JSON y generar una contraseña distinta por perfil en un directorio privado. Guardarla antes de enviar el alta para poder recuperar un intento incierto.
  2. Dar de alta cada cuenta. Enviar su perfil a POST https://data.yokup.com/api/installer/register con Origin: https://www.yokup.com. Guardar la sesión y comprobar HTTP 201, ID y datos.
  3. Crear acceso MCP de lectura. Con esa sesión, llamar a POST /api/installer/mcp-tokens: permiso installer:read, etiqueta de Smith y caducidad de 7 días. Guardar el token de forma privada.
  4. Verificar el titular. Conectar a https://data.yokup.com/mcp/installer, negociar initialize y consultar tools/list, installer_whoami, installer_profile e installer_inbox.
  5. Entregar resultados. Una tabla de 20 filas con ID confirmado, ciudad, especialidad, estado no disponible y resultado MCP. Indicar cualquier fila pendiente; no entregar credenciales.

La guía completa incluye cuerpos, comandos copiables, manejo de cookies, configuración del cliente, límites y recuperación tras errores.

Un lote claramente ficticio

14 perfiles en España y 6 en Portugal. Madrid, Barcelona, Valencia, Sevilla, Málaga, Murcia, Alicante, Zaragoza, Bilbao, Valladolid, A Coruña, Vigo, Salamanca, Badajoz, Lisboa, Porto, Braga, Coimbra, Évora y Faro.

Todos llevan DEMO en el nombre, correo no entregable @example.invalid y available:false. Las coordenadas son aproximaciones de las ciudades. No representan personas, domicilios ni cobertura real de mantenimiento.

Los perfiles de prueba quedan no disponibles desde el alta.

Así no reciben nuevas incidencias ni pueden aceptarlas. La etiqueta DEMO es visible; no constituye un entorno separado. No activar estos perfiles para atender trabajos reales.

Reintentos sin duplicados

Registro y login comparten un límite de 20 intentos por IP cada 15 minutos. Ante 429, detener el lote y esperar al reinicio. Conservar email, contraseña y resultados por fila; si hay conflicto o timeout, reconciliar la misma cuenta antes de repetir. No cambiar el correo para sortear un error.

Los tokens de este lote solo permiten lectura. La guía explica cómo revocar un token perdido o caducado; revocarlo no elimina la cuenta.
